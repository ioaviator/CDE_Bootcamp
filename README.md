# CoreSentiment: Data Pipeline (Apache Airflow)

 CoreSentiment is a stock market prediction tool that applies sentiment analysis on wikimedia page views.

 The focus of this project is to build a data pipeline that extract these page views from wikimedia pages on a per-hour basis and perform ingestion, storage and analysis of the extracted data

 ### Data Source:  [Wikimedia Data](https://dumps.wikimedia.org/other/pageviews/2024/2024-04/)

 ## Technologies
 - SQLite
 - Python
 - Apache Airflow
 - Windows WSL2
